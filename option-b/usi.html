Compliance · v1 plan

USI verification.

Unique Student Identifiers are checked automatically via the USI service, using TRIOX’s own platform USI credential. Example Training Co just switched it on — there are no credentials to set up. Results below are illustrative.

Verified automatically via USI service

Automatic USI checks are on for Example Training Co (sample). Each check runs on enrolment save and before a certificate. A USI is never marked verified just because someone edited it. Values are XXXX-SAMPLE placeholders.

How TRIOX protects the credential

  • Held in a key management service, never shown
  • Separate platform role with MFA and two-person approval
  • Regular rotation and a revocation runbook
  • Every call audited with the RTO and the user
  • Per-RTO limits, so one RTO can be paused without affecting others
