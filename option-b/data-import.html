Integrations / Data import

Import from aXcelerate.

Upload export files and AVETMISS NAT files the RTO supplies. TRIOX never calls aXcelerate’s API and never stores aXcelerate credentials.

Legal review pending
Legal review is pending before this is built. aXcelerate’s API terms bar using their API to replicate or compete with core products. This wizard accepts only files the RTO exports themselves. Nothing is certified automatically after import.
